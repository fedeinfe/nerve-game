Privacy

Last updated: 12 September 2026

The short version

NERVE runs entirely in your browser. There are no accounts, no sign-up, and no cookies. Nothing you do here is sent to a server owned by this game.

What is stored on your device

The game saves five values in your browser's localStorage, on your device only. This is the complete list:

  • nerve.best.daily — today's date and your best score on today's daily run. It is overwritten when a new day starts, so no history of which days you played is kept;
  • nerve.best.endless — your best endless score;
  • nerve.best.alltime — your best score across both modes;
  • nerve.coached — whether you have already seen the first-run hints;
  • nerve.sound — whether you turned sound on or off.

No identifier, no name, no date of birth, no location. These values are never sent anywhere: the game has no server and makes no network request of its own after the page has loaded.

One honest caveat about the address this game is published at. localStorage is shared by every page on the same origin, and fedeinfe.github.io also hosts other projects by the same developer. Any page on that domain can technically read these five values, and a page on a different domain cannot. Nothing on this domain does read them — but a promise that they are unreadable would be a promise the browser does not make, so we do not make it. Clearing your browser's site data removes them. If your browser blocks storage, the game still works; it just will not remember your best score.

Advertising

No advertising is served on this site at the time of writing. No ad network SDK is loaded and no advertising or tracking script runs. If advertising is added in the future, this page will be updated before it goes live, and any consent required in your region will be requested before any tracking takes place.

Analytics

There are none. The game measures nothing and counts nothing — not page views, not runs played, not scores. An earlier draft of this project contained an unused analytics module; it was deleted rather than left dormant, so there is no code here waiting to be switched on. This means the developer genuinely does not know whether you played, and that is the intended state. If analytics are ever added, this page will say so before they run, and any consent required in your region will be asked for first.

Hosting

This site is served as static files by GitHub Pages. Like any web host, GitHub processes connection data (such as IP address) in order to deliver the page. See GitHub's privacy statement.

Fonts

The typeface is loaded from Google Fonts. Both this page and the game request a stylesheet from fonts.googleapis.com and the font file itself from fonts.gstatic.com, so Google receives the connection data any web request carries, including your IP address. These are the only third-party requests either page makes. See Google Fonts' privacy note.

Children

The game is suitable for a general audience, collects no personal data and is not directed at children under 13 for the purposes of data collection.

Contact

NERVE is an independent project by a single developer. For any privacy question, open an issue on the project's GitHub repository.
